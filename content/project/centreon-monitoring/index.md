Diseñé y desplegué un sistema de monitoreo para el datacenter usando **Centreon**, combinando **SNMP**, chequeos activos y métricas personalizadas.  
**Resultados clave:**
- Alertas inteligentes por **Telegram** para incidentes críticos.
- **Dashboards** por rol (redes, sistemas, virtualización).
- Métricas de **disponibilidad**, **latencia**, **uso de CPU/RAM/Disco**, temperatura y energía.
- Plantillas/modos de descubrimiento para hosts nuevos y mantenimiento con mínimos clics.

**Stack técnico:** Linux (Debian/CentOS), Centreon, SNMP, scripts en Bash/Python, Telegram API.
